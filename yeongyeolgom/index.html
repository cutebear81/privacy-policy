연결곰 개인정보 처리방침

최종 수정일: 2026년 11월 21일 · 시행일: 2026년 11월 21일

연결곰(이하 "앱")은 안내문·공유기 스티커·와이파이 QR에 적힌 와이파이 이름과 비밀번호를 카메라로 읽어 연결을 돕는 앱입니다. 모든 처리는 사용자의 기기 안에서 이루어집니다. iCloud 자동 백업이 켜져 있으면(기본 켜짐) 암호화된 백업 파일이 사용자 본인의 iCloud에 저장됩니다. 개발사는 별도의 서버를 운영하지 않으며, 개발사가 볼 수 있는 곳으로 정보를 보내거나 제3자와 공유하지 않습니다. 앱에는 광고, 추적, 이용 분석 기능이 없습니다.

1. 처리하는 정보 및 목적

1-1. 사용자가 직접 넣거나 앱으로 읽은 정보

  • 와이파이 이름, 비밀번호, 보안 방식, 숨겨진 와이파이 여부
  • 내 핫스팟 카드의 별칭
  • 기록을 저장하거나 마지막으로 사용한 날짜

이 정보는 와이파이 연결, 기록 보기, QR 보여 주기, 그리고 iCloud 자동 백업·복원에만 쓰입니다. 개발사 서버로는 보내지 않습니다.

1-2. 기기 권한과 기능

  • 카메라 접근 권한: 안내문·공유기 스티커의 글자와 와이파이 QR을 읽기 위해 사용합니다. 찍은 화면과 사진은 글자를 읽은 뒤 바로 버리며 저장하지 않습니다.
  • 사진 선택: [사진에서]를 누르면 사용자가 고른 사진 한 장만 앱에 전달되며, 글자를 읽은 뒤 저장하지 않습니다. 사진 보관함 전체에 접근하지 않습니다.
  • 와이파이 연결 설정(Hotspot Configuration): 사용자가 [연결]을 누르면 기기에 와이파이 연결 설정을 넣습니다. 연결 전에 기기가 확인 창을 띄우며, 사용자가 승인해야 연결됩니다.
  • 와이파이 정보 확인(Access WiFi Information): 연결 요청 뒤 지금 연결된 와이파이 이름이 요청한 이름과 같은지 확인하는 데만 사용합니다. 이 확인 결과는 저장하지 않습니다.

앱은 위치 권한을 요청하지 않습니다. 카메라 권한은 언제든지 기기 설정에서 해제할 수 있습니다.

1-3. 수집하지 않는 정보

  • 이름, 연락처, 계정 등 개인 식별 정보
  • 위치 정보
  • 광고 식별자(IDFA) 또는 추적 데이터
  • 이용 기록 또는 행태 분석 데이터

2. 기기 내 처리

글자 인식과 QR 읽기는 Apple이 기기에 제공하는 인식 기능으로 기기 안에서 처리되며, 외부 서버로 보내지 않습니다.

3. 정보의 저장

  • 와이파이 이름·보안 방식·별칭·날짜는 앱 내부 저장 공간에 보관합니다. 기기 사이 실시간 동기화는 하지 않으며, iCloud에는 아래 3-1의 암호화된 백업 파일만 둡니다.
  • 비밀번호는 기기 키체인에 '이 기기에서만, 잠금이 풀렸을 때만 읽을 수 있음' 등급으로 따로 보관합니다. 다른 기기로 옮기는 방법은 아래 iCloud 백업뿐입니다.
  • [비밀번호 복사]로 복사한 비밀번호는 이 기기 안에서만 붙여 넣을 수 있고 2분 뒤 자동으로 지워집니다.
  • 앱이 화면 뒤로 가면 앱 전환 화면에 비밀번호와 QR이 보이지 않도록 화면을 흐리게 가립니다.

3-1. 앱의 iCloud 자동 백업·복원

  • iCloud 자동 백업은 기본으로 켜져 있으며, 설정에서 언제든 끌 수 있습니다. 켜져 있으면 기록이나 카드를 넣거나 고치거나 지울 때, 그리고 바뀐 내용이 있는 채로 앱이 화면 뒤로 갈 때 백업을 새로 씁니다.
  • 백업 대상: 기록과 내 핫스팟 카드의 와이파이 이름, 비밀번호, 보안 방식, 숨겨진 와이파이 여부, 별칭, 날짜
  • 백업 파일은 사용자 본인 iCloud의 연결곰 전용 공간에 저장되며, 저장 전에 전체 내용을 AES-256(GCM) 방식으로 암호화합니다. 파일 안에 와이파이 이름과 비밀번호가 평문으로 남지 않습니다.
  • 백업을 여는 열쇠는 사용자의 iCloud 키체인에 따로 보관됩니다. iCloud 키체인은 Apple이 종단 간 암호화로 보호하므로, 같은 Apple 계정에 로그인한 사용자의 기기에서만 열쇠를 꺼낼 수 있습니다. 개발사는 백업 파일과 열쇠 어디에도 접근할 수 없습니다.
  • 앱을 다시 설치하거나 새 기기에서 처음 켜면, iCloud에 있는 백업을 기기로 내려받아 풀어 저절로 불러옵니다. 설정의 [지금 복원]으로 직접 불러올 수도 있습니다. 비밀번호는 다시 이 기기 키체인에 보관하며, 같은 와이파이가 이미 있으면 새로 만들지 않습니다.
  • 다른 기기에서 복원하려면 같은 Apple 계정, iCloud Drive, iCloud 키체인(암호 및 키체인)이 켜져 있어야 합니다.

이와 별개로, 사용자가 iOS의 기기 백업(iCloud 백업 등)을 사용하는 경우 앱 내부 데이터가 해당 백업에 포함될 수 있으며, 이는 Apple의 정책에 따릅니다. 이 기기 전용 등급으로 보관한 비밀번호는 기기 백업으로 다른 기기에 옮겨지지 않습니다.

4. 제3자 제공

본 앱은 사용자의 정보를 제3자에게 공유·제공·판매하지 않습니다. 설정의 단축어 추가 버튼이나 본 처리방침 링크를 누르면 Apple의 단축어 앱이나 웹 브라우저가 열리며, 이때는 해당 서비스의 정책이 적용됩니다. 앱은 이 과정에서 와이파이 정보를 함께 보내지 않습니다.

5. 보관 및 삭제

  • 기록과 내 핫스팟 카드는 사용자가 앱에서 지우거나 앱을 삭제할 때까지 보관됩니다.
  • iCloud 백업은 사용자가 설정의 [iCloud 백업 지우기]를 누를 때까지 사용자의 iCloud에 남습니다. 앱을 삭제해도 iCloud 백업은 지워지지 않으며, 지우기를 누르면 백업 파일과 백업 열쇠를 함께 지우고 자동 백업을 끕니다.
  • 기록을 지울 때 '기록과 기기의 연결 설정 모두 지우기'를 고르면 연결곰이 넣은 와이파이 연결 설정도 기기에서 지웁니다. 연결곰이 넣지 않은 연결 설정은 지울 수 없습니다.
  • 앱을 삭제하면 앱 내부 데이터가 함께 삭제됩니다. 기기 키체인에 남을 수 있는 비밀번호는 앱을 다시 설치해 처음 켤 때 모두 지웁니다(iCloud 키체인의 백업 열쇠는 복원을 위해 남깁니다).

6. 이용자의 권리

  • 앱에서 기록과 카드를 직접 확인·수정·삭제
  • 카메라 권한을 허용하거나 해제
  • 앱을 삭제하여 앱 내부 데이터를 한 번에 삭제
  • iCloud 자동 백업을 끄거나 켜기, 백업을 직접 불러오거나 지우기

7. 아동의 개인정보

본 앱은 개인 식별 정보를 수집하지 않습니다.

8. 방침의 변경

본 개인정보 처리방침은 법령·정책·앱 기능의 변경에 따라 갱신될 수 있습니다. 변경 사항은 본 페이지에 게시되며 게시 즉시 효력이 발생합니다.
